# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability
We take the security of Distributed Task Engine seriously. If you discover a vulnerability, please do NOT disclose it in public issues.

Please send an email to `prachizala2003@gmail.com` with:
- Description of the vulnerability and attack vector
- Steps to reproduce or proof-of-concept payload
- Potential impact and affected endpoints

We acknowledge reports within 48 hours and provide patches as quickly as possible.
